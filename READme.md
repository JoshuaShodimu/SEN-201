📝 Project Title: TaskMaster API
TaskMaster is a simple web-based system built to help users manage their daily chores or work tasks. It allows you to add tasks, view them, update their status, and delete them when finished.

⚙️ How the Project was Built (SDLC)
The project followed the Software Development Life Cycle (SDLC) steps:

Planning: I decided to build a tool that handles four main actions: Create, Read, Update, and Delete (CRUD).

Naming (Nomenclature): To keep the code organized, I used specific names:

Task: The name of the item being saved.

title: The name of the task.

description: The details of the task.

is_completed: A Yes/No check to see if the task is done.

Coding: I used the Python language and the Flask framework to build the actual tool.

Testing: I checked the tool to make sure that when you click "Delete," the task actually disappears.

Deployment: This is the final step where the code is moved from my computer to a live server so others can use it.

🚀 How to Run the Project
1. Requirements
You need to have Python installed on your computer.

2. Installation
Open your terminal or command prompt and install the web framework:

Bash

pip install flask
3. Running the App
Run the script using this command:

Bash

python app.py
The app will start running at http://127.0.0.1:5000.

🛠 Features
Add a Task: Create a new thing to do.

View All Tasks: See your entire list.

Update Task: Mark a task as "Finished."

Delete Task: Remove a task from the list forever.
